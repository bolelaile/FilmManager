# FilmManager 架构分层

> v1.4.2 分层架构。6 层单向依赖，功能模块独立封装，便于单独升级或替换。

## 分层总览

```
┌─────────────────────────────────────────────────────────────┐
│ 6. UI 层            renderer/components + renderer/services  │  React 组件，仅依赖 store/hooks/service-client
├─────────────────────────────────────────────────────────────┤
│ 5. 应用协调层       main/app + main/index + renderer/pages    │  DI 装配、窗口/生命周期、页面协调
├─────────────────────────────────────────────────────────────┤
│ 4. IPC 适配层       main/ipc (9 个薄 adapter)                │  注册 IPC + 转发到 Service，无 SQL/业务
├─────────────────────────────────────────────────────────────┤
│ 3. 功能核心层       main/features (12 个功能模块)             │  独立 Service 封装，依赖 Repository/工具
├─────────────────────────────────────────────────────────────┤
│ 2. 数据访问层       main/data (7 个 Repository)              │  封装全部 SQL，暴露领域模型与接口
├─────────────────────────────────────────────────────────────┤
│ 1. 基础设施层       main/infra + main/db + main/workers       │  DB 连接/迁移、配置、日志、Worker Pool、图像工具
└─────────────────────────────────────────────────────────────┘

shared/  跨进程共享类型 + Service 接口契约
```

**依赖规则**：上层单向依赖下层；功能核心不直接 `getDb()`/`ipcMain`；IPC 适配层仅参数转换+转发；UI 经 service-client 调用。

## 各层详细说明

### 1. 基础设施层 `main/infra/` + `main/db/` + `main/workers/`

| 模块 | 职责 |
|---|---|
| `infra/image-utils.ts` | 纯图像工具（isRawFormat/normalizeRotation/computeContentHash/extractEmbeddedJpeg/decodeBmp） |
| `infra/config.ts` | 库根目录配置读写（config.json） |
| `infra/ipc-bus.ts` | IPC handle/send 统一封装（隔离 electron） |
| `db/index.ts` | SQLite 初始化（WAL+外键）、16 次增量迁移、种子数据（属性/地点/相机画幅/导出预设）、db_meta 版本门控 |
| `workers/worker-pool.ts` | 4 线程 Worker 池（task→worker 归属、崩溃批量 reject+重建、terminating 标志） |
| `workers/thumbnail-worker.ts` | 子线程内 sharp 生成缩略图 |

### 2. 数据访问层 `main/data/`

| Repository | 职责 |
|---|---|
| `PhotoRepository` | 分页查询（buildPhotoFromClause 多 JOIN+递归 CTE）、COUNT、属性批量加载、时间线、CRUD、删除（原子化）、旋转、收藏 |
| `SubLibraryRepository` | 树（buildTree）、计数（递归 CTE 含后代）、CRUD、folder_name 分配 |
| `AttributeRepository` | 类型/值 CRUD、faceted valueCounts（排除自身类型联动计数）、别名、JSON 导入、图标值查询 |
| `RollRepository` | 卷列表（含封面/属性摘要/地点/shot_date_min）、photolessCount、卷内照片分页、CRUD |
| `LocationRepository` | 地点 CRUD、照片-地点关联（批量 set/clear）、地图数据、坐标缓存 |
| `ExportPresetRepository` | 预设 CRUD、内置幂等插入、旧版 config 迁移 |
| `ImportQueueRepository` | 导入队列表读写（两阶段导入追踪） |

`data/index.ts` 提供 `createRepositories(db)` 工厂，一次构造全部 Repository。

### 3. 功能核心层 `main/features/`

每个功能一个目录，对外暴露 Service（`index.ts`），内部可分子模块。

| 功能 | Service | 子模块 | 行数 |
|---|---|---|---|
| `photos/` | PhotoService | — (COUNT 缓存/全屏预览单飞/pan-zoom) | ~250 |
| `import/` | ImportService | folder-scanner（名称解析/属性匹配）、equipment-resolver（EXIF 器材）、gps-linker（GPS 缓存）、sublibrary-resolver（自动整理） | ~550 |
| `rolls/` | RollService | — (建卷/删除三档/批量/属性一致性) | ~140 |
| `attributes/` | AttributeService | — (faceted/图标/别名/JSON 导入) | ~170 |
| `sublibrary/` | SubLibraryService | — (委托 library-layout 同步磁盘) | ~40 |
| `locations/` | LocationService | osm-geocoder（OSM 在线搜索/反向地理编码） | ~80+60 |
| `library/` | LibraryService | — (ICC/统计/缩略图重生成) | ~90 |
| `stats/` | StatsService | — (仪表盘：按月/胶片/相机/镜头/地点/卷聚合，排除回收站) | ~80 |
| `export/` | ExportService | exportPipeline（解码+编排）、stock-presets（品牌库+工艺墨色）、frame-renderer/（封闭渲染器子模块） | ~330+155+1000 |
| `thumbnails/` | (thumbnail.ts) | — (Sharp 缩略图/EXIF/RAW 解码/胶片格式识别) | ~646 |
| `film-format/` | (film-format.ts) | — (导入/导出共享的格式识别) | ~241 |
| `library-layout/` | (library-layout.ts) | — (磁盘目录树同步/路径竞态) | ~550 |
| `external-apps/` | ExternalAppService | — (检测 30+ 软件/启动) | ~180 |

**frame-renderer/ 封装**（`features/export/frame-renderer/`）：移植自参考项目 film-index-generator 的 3 个核心文件，封闭封装——对外仅暴露 `renderFilmFrame`，内部 shared/frame-135/frame-generic/types 不对外泄露。

### 4. IPC 适配层 `main/ipc/`

9 个薄 adapter，每个仅注册 IPC + 参数转换 + 转发到 Service：

| Adapter | 行数 | 转发到 |
|---|---|---|
| photos.ts | ~36 | PhotoService |
| import.ts | ~52 | ImportService |
| attributes.ts | ~66 | AttributeService |
| rolls.ts | ~40 | RollService |
| sublibraries.ts | ~26 | SubLibraryService |
| library.ts | ~40 | LibraryService |
| locations.ts | ~52 | LocationService |
| export.ts | ~44 | ExportService |
| stats.ts | ~22 | StatsService |
| index.ts | ~52 | 统一注册 + library-layout 同步 |

### 5. 应用协调层

| 模块 | 职责 |
|---|---|
| `main/app/bootstrap.ts` | DI 装配（统一构造 Repository + Service 单例，供 adapter 获取） |
| `main/index.ts` | Electron 窗口/协议/生命周期、app/win IPC、外部软件联动 |
| `renderer/src/pages/Library.tsx` | 页面级状态协调（组合 hooks + 组件 + 全局拖拽导入） |

### 6. UI 层 `renderer/`

| 模块 | 职责 |
|---|---|
| `renderer/services/service-client.ts` | window.api 类型化封装（9 个命名空间：photoService/importService/...） |
| `renderer/src/components/` | 20+ UI 组件（PhotoGrid/PhotoViewer/ExportModal/FilterPanel/RollsView/TimelineView/MapView/ImportDialog 等） |
| `renderer/src/store/` | Zustand 三 slice（filterSlice/librarySlice/uiSlice）+ useStore 组合 |
| `renderer/src/hooks/` | usePhotoLoader（防竞态 loadCounterRef）/ useRollLoader / useLibraryData |

### shared/ 跨进程共享

| 文件 | 职责 |
|---|---|
| `import-types.ts` | ImportOptions / AutoOrganizeMode |
| `export-types.ts` | ExportConfig / FilmFormatId / filmFormatToId / DEFAULT_EXPORT_CONFIG |
| `services/` | Service 接口契约（IPhotoService 等，主/渲染共享类型） |

## 调用链

```
UI 组件 → service-client → preload(window.api) → ipc-adapters → features Service → data Repository → DB
                                                                        ↓
                                                              infra/图像工具 + workers
```
