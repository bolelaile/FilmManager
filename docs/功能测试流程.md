# FilmManager 功能测试流程

> 用于分层架构重构过程中每批次调整后的回归验证。分三层：L1 构建/类型（本环境可跑）、L2 逻辑单测（本环境可跑）、L3 集成测试（需 Windows 开发机 + electron）。

## 测试分层

| 层级 | 内容 | 执行环境 | 命令/方式 |
|------|------|----------|-----------|
| L1 构建 | electron-vite 构建 + tsc 类型检查 | 本环境 | `npm run build` + `npx tsc --noEmit -p tsconfig.node.json` / `tsconfig.web.json` |
| L2 逻辑单测 | 纯逻辑模块（格式识别/stock匹配/路径去重/folder解析/fitPhoto 填满） | 本环境 | esbuild bundle + node 脚本 + 像素采样 |
| L3 集成 | 全功能端到端（导入/查询/导出/卷/地点/外部应用） | Windows 开发机 | `npm run dev` 手动 + `npm run test:layout` |

**每批次后必跑**：L1 + L2。L3 在开发机执行（本沙箱无 electron 二进制），按下方清单逐项核对。

## L2 逻辑单测（本环境可执行）

用 esbuild 把被测 TS 模块 bundle 成 CJS，node 脚本 + Sharp 像素采样验证。

### 2.1 胶片格式识别（film-format / detectFilmFormat）
- 输入：各比例图像（1.0/1.33/1.5/1.67/2.0）+ filmSizeType（135/120/both/null）
- 期望：6×6→`6x6 中画幅`；1.5+135约束→`135 / 35mm`；1.33+135→`半格 / 17.5mm`；120 系列按比例分档

### 2.2 stock 品牌匹配（resolveStock）
- `"Kodak Portra 400 [135 / 35mm]"` → edgeText=`KODAK PORTRA 400`、process=`C-41`、ink 橙
- `"Ilford HP5 Plus"` → process=`BW`、ink 白
- `"Cinestill 800T"` → process=`ECN-2`、ink 米黄
- 未知胶卷 → 回退 C-41

### 2.3 导出渲染填满不变量（fitPhoto / renderFilmFrame）
- 9 画幅 × cover/zoom2/zoom4/角落偏移：帧区背景黑像素=0（始终填满）
- 水平居中：左右 padding 差=0

### 2.4 导出居中
- 各画幅画布垂直中线扫描，左右非背景边界 padding 对称

### 2.5 路径去重与竞态（ensureUniqueFilePath + claimed）
- 同基名并行：claimed 集合消除 TOCTOU，无静默覆盖

### 2.6 folder 名称解析（matchFolderName / parseDateFromName）
- `"2024-03_KodakPortra400_北京"` → 日期+胶片+地点提取

### 2.7 内容哈希（computeContentHash）
- 同内容同哈希；不同内容不同哈希

## L3 集成测试清单（Windows 开发机）

`npm run dev` 启动后逐项操作，核对结果。

### 3.1 启动与初始化
- [ ] 应用启动无错误弹窗；首次启动自动建库 + 种子数据（属性类型/地点/相机画幅/导出预设）
- [ ] 再次启动：日志无 seed/migrate 重跑（seed_version 门控），启动更快
- [ ] 设置页可改库根目录，重启生效

### 3.2 导入
- [ ] 单批次导入：拖放文件夹 → 占位卡片立即出现 → 后台逐张完成（EXIF/拷贝/缩略图）→ 进度条
- [ ] RAW 格式（CR2/NEF/ARW/DNG）导入并生成缩略图
- [ ] BMP 导入（纯 JS 解码器）
- [ ] linked 模式导入：不复制文件，路径为原路径
- [ ] 内容重复照片自动跳过
- [ ] 并行导入同基名文件无覆盖（文件数==成功数）
- [ ] 卷模式导入：子文件夹扫描 → 确认表格属性匹配 → 建卷
- [ ] EXIF GPS 照片自动关联地点（100m 内匹配或新建）
- [ ] 胶片格式自动识别（135/半格/6×6 等）不覆盖手动标注

### 3.3 浏览与筛选
- [ ] 三档视图切换（小/中/大）+ 列数自适应窗口宽度
- [ ] 大视图悬停预览面板
- [ ] 全屏预览：缩放/平移/旋转/左右切换/直方图/属性编辑
- [ ] FilterPanel：子库树（含后代计数）、属性 faceted 联动计数、日期/格式/整理状态/收藏/搜索
- [ ] 筛选 Chips 逐条移除；搜索 300ms 防抖
- [ ] 时间线视图：年月分组、年份多选、月份范围跳转
- [ ] 翻页总数稳定；删除后总数立即更新（COUNT 缓存失效）

### 3.4 胶卷管理
- [ ] 多选建卷（自动命名+封面）
- [ ] 卷视图三档尺寸独立；框选/右键多选
- [ ] 批量属性/批量删除（三档：索引/DB/文件）
- [ ] linked 照片删除卷选"删文件"仍只删 DB
- [ ] 卷内照片分页；移除/添加照片

### 3.5 子库与文件整理
- [ ] 新建/重命名/删除子库同步磁盘目录树
- [ ] 移动照片同步文件 + 路径更新
- [ ] `npm run test:layout` 通过（library-layout 集成）

### 3.6 地点

- [ ] 全屏预览/卷卡片添加/修改/删除地点

### 3.7 导出

## 重构批次测试约定

每批次调整完成后：
1. 本环境跑 **L1 + L2**，排查并解决所有 bug（构建/类型/逻辑）。
2. L3 集成清单提交开发机执行（本沙箱无法跑），记录未通过项。
3. 全部 L1+L2 通过 + L3 已知项记录后，进入下一批次。
